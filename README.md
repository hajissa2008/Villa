# Villa platform

A private view-only copy of the 4D Modeling Platform with the villa model (3D, Plan, Walk, Drive, Drone, floors, BOQ), published as a locked page.

**Open it:** https://hajissa2008.github.io/Villa/ and sign in with the username and password you were given.

The model is stored encrypted (`villa.bin`); without the username and password it cannot be opened. `tools/lock.js` is the script that locks the page.
